1. Introduction: HTML & CSS

What Are HTML and CSS?

HTML (HyperText Markup Language) is the standard markup language used to create the structure and content of web pages. It provides the foundation by defining what elements appear on a webpage and how they are organized.

CSS (Cascading Style Sheets) is a stylesheet language used to control the presentation, layout, and visual appearance of HTML elements. While HTML creates the structure, CSS makes it look good.

Key Distinction: HTML is about "what" (structure and content), while CSS is about "how" (styling and presentation). Together, they form the foundation of modern web development.

Where Are HTML and CSS Used?

  • Websites: Every website on the internet uses HTML and CSS to display content
  • Web Applications: Modern web apps rely on HTML and CSS for user interfaces
  • Email Templates: HTML and CSS are used to create formatted email campaigns
  • Progressive Web Apps (PWAs): Hybrid applications that work on any device
  • Content Management Systems: WordPress, Drupal, and similar platforms use HTML/CSS extensively
  • Mobile Applications: Frameworks like React Native and Flutter build on web technologies

2. HTML Fundamentals

What Is an HTML Tag?

HTML tags are the building blocks of HTML documents. They are keywords enclosed in angle brackets (< and >) that tell the browser how to display content. Tags usually come in pairs: an opening tag and a closing tag.

Tag Structure:

<tagname>Content goes here</tagname>

Example:
<p>This is a paragraph</p>

How Are Tags Used?

Tags serve different purposes in an HTML document. Some tags define structure (like <header>, <section>, <footer>), some define content (like <p>, <h1>, <img>), and some provide metadata (like <meta>, <title>).

Tag Category Examples Purpose
Structural Tags <header>, <nav>, <main>, <footer> Define layout and document structure
Text Tags <p>, <h1>-<h6>, <span>, <strong> Format and organize text content
Media Tags <img>, <video>, <audio> Embed images, videos, and audio
Interactive Tags <button>, <form>, <input> Create interactive elements
Metadata Tags <meta>, <title>, <link> Provide information about the document

Basic HTML Document Structure

Every HTML document follows a standard structure. Understanding this layout is fundamental to web development.

<!-- DOCTYPE declares this as an HTML5 document --> <!DOCTYPE html> <html lang="en"> <head> <!-- Metadata: character encoding, viewport, page title --> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My Website</title> <link rel="stylesheet" href="styles.css"> </head> <body> <!-- All visible content goes here --> <header> <h1>Welcome to My Site</h1> </header> <main> <section> <h2>About Us</h2> <p>This is a paragraph of content.</p> </section> </main> <footer> <p>© 2026 My Website</p> </footer> </body> </html>

Why HTML Structure Matters

  1. Semantic Meaning: Proper structure helps browsers and search engines understand content meaning
  2. Accessibility: Well-structured HTML makes websites usable for people with disabilities
  3. SEO Benefits: Search engines rank properly structured HTML higher
  4. Maintainability: Clean structure makes code easier to update and debug
  5. CSS Targeting: Good structure allows CSS to style elements more effectively
  6. Cross-browser Compatibility: Standard structure ensures websites work across all browsers

Common HTML Tags Explained

<h1> to <h6> - Headings

Define headings, with h1 being the most important and h6 the least. Use them hierarchically.

<h1>Main Title</h1>
<h2>Subtitle</h2>
<p> - Paragraph

Contains blocks of text content.

<p>This is a paragraph.</p>
<a> - Hyperlink

Creates links to other pages or resources.

<a href="https://example.com">Click here</a>
<img> - Image

Embeds images in the document. Self-closing (no closing tag needed).

<img src="image.jpg" alt="Description">
<ul> & <ol> - Lists

ul creates unordered (bullet) lists, ol creates ordered (numbered) lists.

<ul><li>Item 1</li></ul>

3. CSS Fundamentals

What Is CSS?

CSS (Cascading Style Sheets) is used to style and layout HTML elements. It controls colors, fonts, spacing, positioning, and responsive design. CSS uses selectors to target HTML elements and properties to define how they should look.

CSS Rule Structure:

selector { property: value; property: value; }

Example:
p { color: blue; font-size: 16px; }

Internal CSS: Style Within HTML

Internal CSS is written inside the <style> tag within the HTML document's <head> section. This method is useful for single-page websites or when you want to keep all code in one file.

How Internal CSS Works:

<!DOCTYPE html> <html> <head> <title>My Page</title> <style> /* All CSS rules go here */ h1 { color: #667eea; font-size: 2.5em; text-align: center; } p { color: #333; font-size: 1.1em; line-height: 1.6; } .highlight { background-color: yellow; padding: 5px; } </style> </head> <body> <h1>Welcome</h1> <p>This paragraph gets styled by CSS</p> </body> </html>

Advantages of Internal CSS:

  • All code is in one file (good for small projects)
  • Styles apply to the entire HTML document
  • Easy to implement for beginners

Disadvantages of Internal CSS:

  • Cannot be reused across multiple HTML files
  • Makes HTML files larger and harder to manage
  • Not ideal for large projects with multiple pages

External CSS: Style in a Separate File

External CSS is written in a separate .css file and linked to HTML documents using the <link> tag. This is the industry standard and best practice for professional web development.

How External CSS Works:

Step 1: Create a CSS file (styles.css)

/* styles.css */ body { font-family: 'Segoe UI', sans-serif; background-color: #f5f5f5; margin: 0; padding: 0; } h1 { color: #667eea; font-size: 2.5em; } p { color: #333; font-size: 1.1em; line-height: 1.6; } .container { max-width: 1200px; margin: 0 auto; padding: 20px; } #header { background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); color: white; padding: 40px; }

Step 2: Link the CSS file in your HTML document

<!DOCTYPE html> <html> <head> <title>My Website</title> <!-- Link external CSS file --> <link rel="stylesheet" href="styles.css"> </head> <body> <div id="header"> <h1>Welcome</h1> </div> <div class="container"> <p>This content is styled by external CSS</p> </div> </body> </html>

Advantages of External CSS:

  • One CSS file can style multiple HTML pages
  • Keeps HTML and CSS separated (clean code)
  • Easier to maintain and update styles across entire website
  • CSS file can be cached by browsers (faster loading)
  • Industry standard for professional development

Disadvantages of External CSS:

  • Requires an additional file to manage
  • Extra HTTP request needed to load the CSS file

Internal vs. External CSS: Comparison

Aspect Internal CSS External CSS
Location Inside <style> tag in <head> Separate .css file
Scope Single HTML document only Multiple HTML documents
Best For Small projects, single pages Large projects, multiple pages
Code Organization Mixed with HTML Completely separated
Reusability None - styles limited to one file Full - reuse across all pages
File Size Larger HTML file Smaller HTML files
Browser Caching No benefit CSS cached for faster loading
Professional Use Not recommended Industry standard

CSS Selectors: Targeting Elements

CSS selectors are patterns used to select the HTML elements you want to style. There are several types:

1. Element Selector

Targets all instances of an HTML element.

p { color: blue; } — Styles all <p> elements
2. Class Selector

Targets elements with a specific class attribute (prefix with a dot).

.highlight { background-color: yellow; }
<p class="highlight">This is highlighted</p>
3. ID Selector

Targets a single element with a specific ID (prefix with #). Each ID should be unique.

#header { background-color: blue; }
<div id="header">Header content</div>
4. Descendant Selector

Targets elements nested within other elements.

.container p { color: green; } — Styles all <p> inside elements with class "container"

Common CSS Properties

Property Purpose Example
color Text color color: #667eea;
background-color Background color background-color: #f5f5f5;
font-size Text size font-size: 1.2em;
font-family Font type font-family: Arial, sans-serif;
padding Space inside element padding: 20px;
margin Space outside element margin: 10px;
border Element border border: 2px solid #333;
text-align Text alignment text-align: center;
width / height Element dimensions width: 100%; height: 200px;
display Layout type (block, inline, flex, grid) display: flex;

4. Where These Technologies Are Used in Practice

Real-World Applications

📱 Social Media Platforms

Websites like Facebook, Instagram, Twitter, and LinkedIn use HTML for structure and CSS for the beautiful, responsive interfaces you interact with daily.

🛒 E-Commerce Websites

Amazon, eBay, Shopify, and other e-commerce platforms rely heavily on HTML for product pages and CSS to create engaging shopping experiences.

📰 News and Media Sites

News websites (BBC, CNN, The Guardian) use HTML to organize articles and CSS to create readable, attractive layouts.

🎓 Learning Platforms

Educational sites like Coursera, Udemy, and Khan Academy use HTML and CSS for course pages, user profiles, and interactive learning interfaces.

🏢 Corporate Websites

Businesses use HTML and CSS to create professional websites that showcase their brand, services, and products.

📧 Email Marketing

HTML and CSS are used to create visually appealing email templates for marketing campaigns.

The Development Workflow

Professional developers typically follow this workflow:

  1. Plan: Determine the website structure and design
  2. Create HTML: Write semantic, well-structured HTML code
  3. Style with CSS: Create external CSS files to style the elements
  4. Add Interactivity: Use JavaScript to add dynamic features (next step after HTML/CSS)
  5. Test: Check on multiple browsers and devices
  6. Optimize: Improve performance and user experience
  7. Deploy: Publish to the web

5. Key Takeaways

Essential Concepts to Remember

  • HTML provides structure, while CSS provides styling and presentation
  • Tags are HTML's building blocks — they tell browsers how to interpret content
  • Proper HTML structure matters for accessibility, SEO, and maintainability
  • Internal CSS works for small projects; external CSS is the professional standard
  • CSS selectors (elements, classes, IDs) allow precise styling control
  • Learning HTML & CSS is essential for any web development career
  • HTML & CSS together form the foundation of all modern web applications
