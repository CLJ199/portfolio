Section 1
☕ What is Java?
📌 Overview, History & Key Features
☕ Definition
Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible. It was originally developed by James Gosling at Sun Microsystems and released in 1995. Today it is owned and maintained by Oracle Corporation. Java follows the philosophy of "Write Once, Run Anywhere" (WORA) — meaning compiled Java code can run on any device that has the Java Virtual Machine (JVM) installed.
🔑 Key Features of Java
F1
Platform Independent
Java source code is compiled into bytecode (not machine code). This bytecode runs on the JVM, which is available on Windows, macOS, and Linux — so the same program runs everywhere.
💡 "Write Once, Run Anywhere" (WORA)
F2
Object-Oriented
Everything in Java is organised around classes and objects. This makes programs modular, reusable, and easier to maintain.
F3
Strongly Typed
Every variable must be declared with a specific data type before it is used. Java checks types at compile time, catching errors early.
F4
Secure & Robust
Java has built-in features to prevent common programming errors, including automatic garbage collection (memory management), exception handling, and strong type-checking.
F5
Case-Sensitive
Java is case-sensitive. This means myVariable, MyVariable, and MYVARIABLE are three completely different identifiers.
⚠️ Very common source of beginner errors!
🏗️ Java Technology Stack
Component Full Name What it Does
JDK Java Development Kit The full toolkit for writing, compiling & running Java programs
JRE Java Runtime Environment Allows you to run (but not write) Java programs
JVM Java Virtual Machine Executes Java bytecode on your specific operating system
Bytecode Compiled Java Code Intermediate code (.class file) that the JVM can understand
📌 Key Workflow: You write .java source code → The Java Compiler (javac) compiles it into a .class bytecode file → The JVM runs the bytecode on your machine.
Section 2
🛠️ The JGrasp IDE
📌 What is JGrasp & How to Use It
🛠️ What is an IDE?
An IDE (Integrated Development Environment) is a software application that provides a complete environment for writing, compiling, running, and debugging code — all in one place. Instead of using separate tools, an IDE bundles everything a programmer needs into a single interface.
💡 Think of an IDE like a fully equipped workshop — it has your workbench (editor), tools (compiler), and testing area (debugger) all in one room.
☕ What is JGrasp?
JGrasp is a lightweight IDE developed at Auburn University, specifically designed for teaching programming. It is particularly popular in educational settings because it is free, simple to use, and includes built-in visualisation tools that help beginners understand how programs work. JGrasp supports Java, C, C++, Python, and other languages.
🖥️ Key Parts of the JGrasp Window
P1
Source Code Editor (Top Panel)
The main area where you type your Java code. JGrasp provides syntax highlighting (different colours for keywords, strings, etc.) and auto-indentation to make code readable.
P2
Run I/O Window (Bottom Panel)
Displays the output of your program when it runs, and accepts keyboard input when your program asks for it.
P3
Toolbar Buttons
Key buttons include:
🔨 Compile — converts your .java file to bytecode (.class file)
▶️ Run — executes your compiled program
🐛 Debug — runs your program step by step to find errors
⚠️ You MUST compile successfully before you can run a program.
P4
CSD (Control Structure Diagram)
A unique JGrasp feature. It automatically generates a visual diagram of your program's control flow (loops, if-statements, etc.) alongside your code, helping beginners understand the program's structure at a glance.
📁 File Naming Rules in JGrasp
⚠️
Critical Rule: File Name Must Match Class Name
In Java, the filename must exactly match the public class name, including capitalisation. The file must be saved with a .java extension.
✅ Class named HelloWorld → File must be saved as HelloWorld.java
❌ Class named HelloWorld → File saved as helloworld.java — this will cause a compile error!
Section 3
🏗️ Java Program Structure
📌 Anatomy of a Java Program
HelloWorld.java // This is a single-line comment — the compiler ignores this line public class HelloWorld { // Class declaration public static void main(String[] args) { // Main method — program starts here System.out.println("Hello, World!"); // Print a line of text } // end of main method } // end of class
🔍 Breaking Down Each Part
1
public class HelloWorld
This declares a class named HelloWorld. In Java, every program must be inside a class. The word public is an access modifier — it means this class is accessible from anywhere. The class name must match the filename exactly.
2
public static void main(String[] args)
This is the main method — the entry point of every Java application. When you run a Java program, the JVM looks for and executes this method first. You must write it exactly as shown — it is case-sensitive and must include every keyword.
⚠️ Without this exact method signature, your program will not run.
3
Curly Braces { }
Curly braces define blocks of code. Every opening brace { must have a matching closing brace }. The class body sits between the class braces; the method body sits between the method braces.
4
Semicolons ;
In Java, every statement must end with a semicolon. Forgetting a semicolon is one of the most common beginner errors and will cause a compile error.
⚠️ Note: Class and method declarations do NOT end with semicolons — only statements inside them do.
5
System.out.println("Hello, World!");
This statement prints the text "Hello, World!" followed by a new line to the screen. System is a built-in Java class, out is an output stream, and println is the method that prints text with a line break.
Method What it Does Example
System.out.println() Prints text + moves to a new line System.out.println("Hi!");
System.out.print() Prints text without moving to a new line System.out.print("Hi ");
Section 4
🔢 Data Types
📌 Primitive Data Types in Java
🔢 What is a Data Type?
A data type tells Java what kind of value a variable will hold. Because Java is strongly typed, you must declare the type of every variable before using it. Java has 8 primitive data types (built-in, simple types) and also supports reference types like String.
Data Type Category Size What it Stores Example Value
int Integer 32-bit Whole numbers (no decimals) 42
double Floating Point 64-bit Decimal / fractional numbers 3.14
char Character 16-bit A single character (letter, digit, symbol) 'A'
boolean Logical 1-bit Only two values: true or false true
float Floating Point 32-bit Decimal numbers (less precise than double) 3.14f
long Integer 64-bit Very large whole numbers 1000000L
byte Integer 8-bit Very small whole numbers (-128 to 127) 100
short Integer 16-bit Small whole numbers (-32768 to 32767) 200
String Reference Type Variable A sequence of characters (text) — not a primitive! "Hello"
📌 Key Distinctions to Remember:
• char values use single quotes: 'A'
• String values use double quotes: "Hello"
• float literals must end with f: 3.14f
• long literals must end with L: 1000000L
• String starts with a capital S — it is a class, not a primitive type.
Section 5
📦 Variables
📌 Declaring, Initialising & Naming Variables
📦 What is a Variable?
A variable is a named storage location in memory that holds a value. In Java, before you can use a variable, you must declare it by specifying its data type and giving it a name (identifier). You can also optionally initialise it (give it a starting value) at the same time.
💡 Think of a variable as a labelled box — the type defines what kind of thing can go in the box, and the name is the label on the box.
📝 Syntax: How to Declare a Variable
Variables.java // Syntax: dataType variableName; // Syntax: dataType variableName = value; public class Variables { public static void main(String[] args) { // Declaration only int age; // Declaration + Initialisation int score = 95; double price = 9.99; char grade = 'A'; boolean isPassed = true; String name = "Lena"; // Assigning a value after declaration age = 17; // Updating a variable's value score = 100; System.out.println("Name: " + name); System.out.println("Age: " + age); System.out.println("Score: " + score); } }
📏 Variable Naming Rules & Conventions

No spaces allowed Use camelCase for multi-word names ✅ firstName   ❌ first name
Case-sensitive age and Age are different score ≠ Score ≠ SCORE
Cannot use Java keywords Reserved words are off limits ❌ int, class, static

💡
Constants — The final Keyword
A constant is a variable whose value cannot be changed after it is set. In Java, use the final keyword to declare a constant. By convention, constants use ALL_UPPER_CASE with underscores.
final double PI = 3.14159; final int MAX_SCORE = 100;

Section 7
📤 Input & Output
📌 Displaying Output & Reading User Input
OUT
Output — Displaying Information to the Screen
Java uses System.out.println() and System.out.print() to display output. You can combine text and variable values using the concatenation operator +.
OutputDemo.java int age = 17; String name = "Lena"; // Concatenation: combining text + variables System.out.println("Name: " + name); System.out.println("Age: " + age); System.out.println("In 3 years: " + (age + 3)); // print() stays on the same line System.out.print("Hello "); System.out.print("World"); // Output: Hello World (on one line)
IN
Input — Reading Data from the Keyboard using Scanner
To read input from the user, Java uses the Scanner class, which is found in the java.util package. You must import it at the top of your file before using it.
InputDemo.java import java.util.Scanner; // Step 1: Import Scanner public class InputDemo { public static void main(String[] args) { // Step 2: Create a Scanner object Scanner input = new Scanner(System.in); // Step 3: Prompt the user System.out.print("Enter your name: "); // Step 4: Read input into a variable String name = input.nextLine(); System.out.print("Enter your age: "); int age = input.nextInt(); // Step 5: Use the input System.out.println("Hello, " + name + "! You are " + age + " years old."); input.close(); // Step 6: Close the Scanner when done } }

💬 Comments
📌 Types of Comments in Java
💬 What is a Comment?
A comment is a note written in the source code that the compiler completely ignores. Comments are written for humans — to explain what the code does, why a decision was made, or to temporarily disable code during testing. Good commenting is a sign of a professional, thoughtful programmer.
Comments.java // ── 1. Single-line comment ────────────────────────── // Starts with // and runs to the end of the line. // The compiler ignores everything after the // int x = 10; // You can also place them at the end of a line /* ── 2. Multi-line comment ───────────────────────── Starts with /* and ends with */ Useful for longer explanations that span multiple lines. */ /** * ── 3. Javadoc comment ─────────────────────────── * Starts with /** and ends with */ * Used to generate official documentation. * Appears before classes and methods. * * @param args command-line arguments * @author Lena */ public static void main(String[] args) { }
TypeSyntaxBest Used For
Single-line // comment Quick notes, short explanations
Multi-line /* comment */ Longer explanations, temporarily disabling code
Javadoc /** comment */ Documenting classes, methods, and parameters formally
📌 Best Practice: Always comment your code as you write it — not after. Describe the purpose of your code (the "why"), not just what it does (the "what"), since the code itself already shows what it does.

📝 Section E — Short Answer Questions 5 marks each = 15 marks
E1
Short Answer 5 marks
Explain the difference between JDK, JRE, and JVM. In your answer, explain what each one is, what it does, and how they relate to each other in the process of running a Java program.
Words: 0
📋 Marking Guide (5 marks):
• 1 mark — JDK correctly described as the full development toolkit (includes compiler, JRE, libraries, debugging tools)
• 1 mark — JRE correctly described as the environment for running (not writing) Java programs (includes JVM + class libraries)
• 1 mark — JVM correctly described as the component that executes bytecode on the specific host operating system
• 1 mark — Correct relationship explained: JDK contains the JRE, which contains the JVM
• 1 mark — Workflow described: .java source code → compiled by JDK into .class bytecode → JVM executes it on any platform
👁️ View Model Answer

The JDK (Java Development Kit) is the complete package a developer needs to write, compile, and run Java programs. It includes the Java compiler (javac), the JRE, standard libraries, and debugging tools. It is what you install when you want to create Java programs.

The JRE (Java Runtime Environment) is a subset of the JDK. It contains everything needed to run Java programs — specifically the JVM and the standard class libraries — but it does not include the compiler. End users who only want to run Java applications (not develop them) install the JRE.

The JVM (Java Virtual Machine) is the core component that actually executes the compiled bytecode (.class files). The JVM is platform-specific — there is a separate JVM for Windows, macOS, and Linux — but because all bytecode looks the same to the JVM, the same .class file runs on any of them.

Relationship: JDK ⊇ JRE ⊇ JVM. The workflow is: the developer writes .java source code → the JDK's compiler converts it to .class bytecode → the JVM (inside the JRE) executes that bytecode on the user's machine.
